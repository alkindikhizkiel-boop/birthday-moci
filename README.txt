BIRTHDAY WEBSITE — FOR MOCI ♡

ISI FOLDER
- index.html        : halaman utama
- rahasia.html      : halaman rahasia yang dibuka dari QR Code
- assets/           : tempat foto-foto

CARA MEMASUKKAN FOTO
1. 19 foto Moci sudah dimasukkan ke folder assets.
2. Beri nama persis:
   moci-1.jpg
   moci-2.jpg
   moci-3.jpg
   moci-4.jpg
   moci-5.jpg
   moci-19.jpg
3. Foto hadiah yang kamu kirim sudah dimasukkan dengan nama:
   foto-hadiah.jpg
4. Jika foto format PNG, ubah ekstensi pada nama file dan sesuaikan juga nama di HTML.

MUSIK
Tombol musik membuka video resmi Katy Perry — Birthday di YouTube:
https://www.youtube.com/watch?v=CEUg7OplvIQ
Karena kebijakan browser dan YouTube, musik dibuka di YouTube (bukan dipaksa autoplay diam-diam di halaman).

QR CODE
QR Code dibuat otomatis saat tombol "Open your gift" diklik. QR akan mengarah ke rahasia.html pada domain tempat website di-hosting.
PENTING: QR lintas perangkat baru berfungsi setelah folder website diunggah ke hosting publik. Jangan scan dari file lokal di komputer.

CARA PUBLISH GRATIS DENGAN GITHUB PAGES
1. Buat akun/login di https://github.com
2. Buat repository baru, misalnya birthday-moci (Public).
3. Upload index.html, rahasia.html, dan folder assets beserta foto.
4. Buka Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu proses selesai. Link website akan muncul di halaman Pages.
8. Buka link itu dari HP untuk tes. Tombol QR akan mengarah ke halaman rahasia pada website yang sama.

CATATAN
- Semua file bisa diedit dengan VS Code atau Notepad.
- QR Code memerlukan koneksi internet untuk memuat pustaka QR dari CDN.
- Pastikan foto yang dipakai memang boleh dibagikan melalui link publik. Siapa pun yang memiliki link website/QR dapat melihatnya.
